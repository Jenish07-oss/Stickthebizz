# Project Rules & Guidelines for StickTheBizz

1. **Targeted Code Reading & Token Efficiency (Strict User Rule)**:
   - Only read the specific files and code lines directly related to the issue or requested change.
   - Do NOT scan, read, or grep through the full project or unrelated directories.
   - Conserve tokens, context window, and execution time by pinpointing exact symbols, functions, and lines needed for the fix.

2. **Single-Page Standee Printing**:
   - The acrylic counter QR standee printout must always print as strictly 1 single page in all browsers (Chrome, Edge, Brave, Safari).
   - Use isolated document frames or print media isolation to ensure the multi-page dashboard DOM never bleeds into print previews.
